# fMRI  part1
fMRI Explained | Part 1: How Task Signals Become BOLD Signals

The connection between the neural activity and the recorded Blood Oxygen Level Dependent (BOLD) signal is one of the important concepts in the fMRI (functional Magnetic Resonance Imaging) analysis.



When a person takes part in a test in the course of an fMRI scan, his/her brain does not react immediately. In order to model this process, the Hemodynamic Response Function (HRF) is used.
